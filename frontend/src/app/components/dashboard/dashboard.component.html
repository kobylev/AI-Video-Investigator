ABOUT PROJECT

AI Video Investigator is a privacy-preserving dual-agent semantic video retrieval system designed for security and dashcam footage. It integrates a local lightweight edge model (FAISS + OpenCLIP) for ultra-fast, GDPR-compliant filtering under 100ms, combined with a cloud-based multimodal reasoning agent (Claude Haiku 4.5) for deep confirmation of ambiguous events.
